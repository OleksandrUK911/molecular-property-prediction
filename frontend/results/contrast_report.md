## Remaining items left as-is

- **White text on `--text-muted` (disabled submit button).** WCAG explicitly
  exempts inactive/disabled UI components from contrast requirements
  ("Understanding SC 1.4.3" / "Understanding SC 1.4.11": a disabled control
  has no contrast minimum since it conveys no actionable information). Left
  unchanged in both themes; the script marks it "N/A (exempt)" rather than a
  real failure.
- **`--border` on `--surface` (icon-button divider, 1.18:1 / 1.24:1).** This
  is a subtle decorative outline around the theme-toggle and language-select
  controls. It is not the sole means of identifying those controls — they
  already have a visible label/icon and a background (`--surface`) that
  contrasts adequately against the page background (`--bg`), so the button's
  boundary is perceivable without relying on the border color. Raising the
  border to a true 3:1 divider would require a near-black/near-white line
  that clashes with the rest of the (deliberately subtle) UI chrome for a
  marginal accessibility gain over an already-identifiable control. Judged
  not worth the visual regression; left as a known, documented gap rather
  than silently passing or silently failing.
