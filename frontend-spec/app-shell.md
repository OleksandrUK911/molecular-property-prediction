# App shell

Спільний каркас над усіма сторінками (`Predict`, `History`, `About`).

## Layout

```
┌──────────────────────────────────────────────┐
│  Logo  Predict  History  About        [🌐 EN] │  ← header, sticky top
├──────────────────────────────────────────────┤
│                                                │
│              (сторінка, див. */-page.md)      │
│                                                │
└──────────────────────────────────────────────┘
```

Без sidebar — для MVP-масштабу проєкту (3 сторінки) горизонтальний header з
трьома пунктами навігації достатній; sidebar над-інженерство для цього
обсягу функціоналу (узгоджено з приміткою в `TODO/frontend/TODO_dashboard_layout.md`).

- Header: логотип/назва зліва, 3 навігаційні лінки по центру/зліва-від-центру,
  перемикач мови (EN/UK) справа.
- Активна сторінка підсвічена в навігації (underline або bold).
- На мобільному (<640px): навігаційні лінки залишаються в один рядок (лише 3
  пункти — не потребують burger-меню).

## Глобальні стани
- **Error boundary:** якщо рендер будь-якої сторінки падає — весь контент під
  header замінюється на "Something went wrong" + кнопка "Reload page" (header
  лишається видимим і клікабельним).
- **Мова (i18n):** стан локалі на рівні застосунку, впливає на всі сторінки
  одночасно (див. `frontend/TODO_i18n_localization.md`).
- **Тема (dark/light):** P2, не блокує MVP.
