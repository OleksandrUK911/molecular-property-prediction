# Data visualization spec

## Descriptor bar chart

**Розташування:** Predict page, під двома колонками (структура + картка результатів), на всю ширину контейнера (~700px).

**Тип:** вертикальний bar chart (Recharts `BarChart`).

**Проблема:** дескриптори мають дуже різні шкали (MolWt ~100–500, LogP
~−2…5, TPSA ~0–150, H-Bond Donors ~0–5, Rotatable Bonds ~0–10, Num Rings
~0–4) — пряме відображення в одному bar chart спотворює маленькі значення.

**Рішення для MVP:** нормалізувати кожен дескриптор до 0–1 відносно
фіксованого референсного діапазону (типового для drug-like молекул, за
правилом Lipinski / QED-подібними межами), а не відносно min/max поточного
датасету:

| Дескриптор | Референсний діапазон (0→1) |
|---|---|
| MolWt | 0–500 |
| LogP | −2–5 |
| TPSA | 0–140 |
| H-Bond Donors | 0–5 |
| Rotatable Bonds | 0–10 |
| Num Rings | 0–6 |

- Вісь X: категорії дескрипторів (6 барів)
- Вісь Y: 0–1 (нормалізоване значення)
- Tooltip на кожному барі показує ОРИГІНАЛЬНЕ (ненормалізоване) значення з
  одиницями, не нормалізоване число
- Колір барів: один нейтральний акцентний колір (не потрібне кодування
  кольором для MVP)

## Індикатор впевненості (P2, опційно)
Якщо модель повертає uncertainty-оцінку: горизонтальна шкала 0–100%
("Confidence") з кольоровим градієнтом (червоний→зелений) і позначкою
поточного значення. Показується як частина `ResultsCard`, не окремий графік.

## Графік тренду історії (P2, опційно)
Лінійний графік: вісь X — дата запиту (хронологічно), вісь Y — значення
передбаченої властивості. Показує лише останні N (напр. 20) записів історії
користувача. Актуально тільки якщо історія зберігається (localStorage або
бекенд) — інакше пункт пропускається.

## Доступність
Для bar chart і trend-графіка — текстова/табличну альтернатива (та сама
таблиця значень, доступна через кнопку "View as table" або `<details>`
поруч із графіком) для користувачів, які не сприймають графічне подання.
