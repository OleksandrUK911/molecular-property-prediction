# History page

Шлях `/history`. Список попередніх передбачень поточного користувача/сесії.
Дані — з `GET /history`, точна схема рядка — [../backend-spec/api-contract.md](../backend-spec/api-contract.md#get-history).

## Layout

```
┌──────────────────────────────────────────────────────┐
│ Prediction history                                     │
│ ┌───────┬────────────────┬──────────┬──────────┬─────┐│
│ │ Thumb │ SMILES (trunc) │ Predicted│ Date     │ ⋮   ││
│ ├───────┼────────────────┼──────────┼──────────┼─────┤│
│ │ [img] │ CC(=O)Oc1ccc...│ -2.31    │ Sep 11   │View ││
│ │ [img] │ Cn1cnc2c1c(=O)…│ -0.55    │ Sep 10   │View ││
│ └───────┴────────────────┴──────────┴──────────┴─────┘│
└──────────────────────────────────────────────────────┘
```

Таблиця, 5 колонок: thumbnail (мала 2D-структура ~40x40px), SMILES (обрізаний
з `title`-tooltip повного рядка), predicted value, дата запиту, дія
(View → повертає на Predict з передзаповненим SMILES і одразу показаним
результатом з кешу, без повторного запиту до API).

На мобільному: колонки Thumb+SMILES+Predicted лишаються, Date ховається
(доступна через розгортання рядка / деталі), таблиця скролиться горизонтально
в межах своєї картки (не весь layout).

## Стани

| Стан | Що видно |
|---|---|
| **Loading** | 3–5 skeleton-рядків замість таблиці (сірі прямокутники на місці thumbnail/тексту) |
| **Empty** | Немає записів історії: центрований блок "No predictions yet" + кнопка "Make your first prediction" → `/` |
| **Populated** | Таблиця, найновіший запис зверху |
| **Error** | Банер "Could not load history" + Retry (тільки якщо історія зберігається на бекенді, а не в localStorage) |

## Сховище історії
Вирішено: історія зберігається на бекенді (Postgres/SQLite, див.
`backend/TODO_database.md`), не в `localStorage` — кожен `POST /predict`
пише рядок server-side, фронтенд лише читає `GET /history`. Тому стани
Loading/Error застосовуються повністю (мережевий запит, а не миттєве
читання з локального сховища).
